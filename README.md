# Nordic-Nook
Landing page 

Nordic Nook is a conceptual landing page designed to capture the quiet luxury of Scandinavian café culture. Moving away from standard web layouts, we built an immersive, editorial digital experience inspired by high-end templates. To avoid generic 'template' aesthetics, we developed bespoke, library-free scroll interactions using vanilla JavaScript—translating vertical scrolling into horizontal panning, cinematic image scaling, and text-masking reveals. The result is a highly tactile, typography-driven site that feels more like flipping through a lifestyle magazine than browsing a webpage.
